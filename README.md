# ⚽ World Cup Analysis

A Data Analysis and Machine Learning project that explores FIFA World Cup match data and analyzes match statistics, goals, attendance, match outcomes, and team performance.

## 📌 Project Overview

This project analyzes historical FIFA World Cup match data using Python and Machine Learning techniques.

The project includes:

- Data loading and preprocessing
- Missing value handling
- Exploratory Data Analysis
- Goal distribution analysis
- World Cup match count analysis
- Correlation analysis
- Feature engineering
- Match outcome classification
- Random Forest Machine Learning model
- Model evaluation

## 🎯 Objectives

- Analyze historical FIFA World Cup match data
- Understand goal-scoring patterns
- Analyze the number of matches played in each World Cup
- Study relationships between match statistics
- Create new features from match data
- Classify match outcomes using Machine Learning
- Evaluate the classification model

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## 📂 Dataset

The project uses three datasets:

### 1. WorldCupMatches.csv

Contains FIFA World Cup match-level information such as:

- Year
- Date and time
- Stage
- Home Team
- Away Team
- Home Team Goals
- Away Team Goals
- Attendance
- Half-time goals
- Referee information
- Match ID
- Round ID

### 2. WorldCups.csv

Contains World Cup tournament-level information.

### 3. WorldCupPlayers.csv

Contains World Cup player-related data.
